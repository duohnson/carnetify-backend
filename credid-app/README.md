Aplicacion y sitio web pensado para la creacion de carnets o credenciales virtuales / digitales.

##### Visitese: (Temporalmente deshabilitado)

Entender que la aplicacion se encuentra en desarrollo, puede experimentar multiples errores.

Si deseas contribuir al desarrollo de la aplicacion, puedes hacerlo a traves de nuestro repositorio en GitHub.

Si desea leer la documentacion de como se va desarrollando la aplicacion, y el proyecto en general por favor lease en:
(La aplicación se esta desarrollando en 3 repositorios divididos, donde carnetify-app es la interfaz de aplicación, carnetify-backend el backend y APIS que unen la aplicación, y carnetify-web la versión web del sistema.)
